# Очередь 420604

Электронная очередь на лабораторные и практические занятия для группы БГУИР 420604.

Что умеет сайт:

- загружает расписание группы из API БГУИР и кэширует его;
- показывает занятия на две недели с датой и подгруппой;
- разделяет общие занятия, первую и вторую подгруппы;
- допускает к очереди только участников утверждённого списка;
- выполняет вход через Telegram-бота;
- продолжает ротацию после последнего реально сдававшего;
- позволяет участнику выйти, отметить сдачу или пропустить человека позади себя;
- даёт администратору возможность менять порядок и состояние очереди;
- позволяет суперадминистратору назначать и снимать администраторов;
- запрещает менять очередь после окончания занятия.

Технологии: Next.js, TypeScript, Vercel Functions, PostgreSQL в Supabase и Drizzle ORM.

## Быстрый запуск

Полная пошаговая инструкция находится в [DEPLOYMENT.md](./DEPLOYMENT.md).

Для локального запуска:

```bash
cp .env.example .env.local
npm ci
npm run dev
```

Затем откройте `http://localhost:3000`. Для полноценного входа через Telegram нужен публичный HTTPS-адрес и настроенный webhook.

## Важные файлы

- `app/` — страницы, интерфейс и серверные API-маршруты;
- `lib/roster.ts` — утверждённый список студентов, подгруппы и администратор;
- `lib/schedule.ts` — расписание БГУИР;
- `lib/queue-data.ts` — логика очередей;
- `db/schema.ts` — структура базы данных;
- `supabase/setup.sql` — готовая схема для новой базы Supabase;
- `.env.example` — шаблон переменных окружения без секретов.

Настоящие пароли и токены в архив не включены.
